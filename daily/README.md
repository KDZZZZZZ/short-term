# Daily 目录

所有内容统一放在 `AB` 目录下，按“人员 / Day”归档。每个 Day 目录包含：

- `daily.md`：完整日报
- `commit.md`：对应的 Gitee commit、主要内容和 GitHub 取材
- `prompt.md`：对应的历史提问记录和整理版提示词
