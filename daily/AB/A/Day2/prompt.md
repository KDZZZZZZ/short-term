## ChatGPT 会话一 · 需求与约束

> 来源：ChatGPT 分享会话一中除提问以外的需求、约束与执行要求汇总，按原文分组保留，此处只列归属本 Day 的条目。敏感凭据已脱敏。

**API 与业务契约**

- OpenAPI 是公开 HTTP API 的唯一真源。
- 非在售商品详情仍然可见，包括 `OFF_SHELF`、`RESERVED`、`SOLD`。
- 联系方式永远不能删除，只能新增或修改。
- 商品存在 `PENDING` 交易时不能下架。
- `RESERVED`、`SOLD` 商品不能编辑字段、加图或删图。
- 商品详情不得泄露学号。
- 卖家联系方式不做本轮额外对称扩展，仍按当前契约执行。
- 其他契约细节由代理补齐，但必须写入文档和测试。
