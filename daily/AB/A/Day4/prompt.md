## ChatGPT 会话一 · 需求与约束

> 来源：ChatGPT 分享会话一中除提问以外的需求、约束与执行要求汇总，按原文分组保留，此处只列归属本 Day 的条目。敏感凭据已脱敏。

**仓库与开发环境**

- 检查阿里云北京服务器环境。
- 允许使用 sudo、Aliyun CLI 或 Workbench 执行服务器配置。
- 不把服务器密码写入仓库、CI 或日志。

**CI、PR 与部署**

- Backend CI 必须执行：OpenAPI 校验、Proto breaking/drift 校验、Go 格式与 vet 与 race 测试、独立容器构建、PostgreSQL 集成测试、REST E2E。
- `main` Backend 成功后自动触发生产部署。
- 部署失败必须让 workflow 失败。
- 有上一版本时自动回滚应用镜像。
- 数据库迁移不自动回滚，必须遵循 expand/contract。
- 当前部署为单机 rootless Podman，不是 Kubernetes。
- Gateway API 使用 `18083`，指标 `19090` 只允许本机访问。
- 当前学习环境允许公网访问 `18083`。
