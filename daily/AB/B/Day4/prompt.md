## ChatGPT 会话一 · 需求与约束

> 来源：ChatGPT 分享会话一中除提问以外的需求、约束与执行要求汇总，按原文分组保留，此处只列归属本 Day 的条目。敏感凭据已脱敏。

**公网 E2E 用户故事**

- 匿名访问受保护接口返回 401。
- 创建卖家、买家、旁观者三个随机测试用户。
- 用户可以读取自己的资料。
- 商品发布成功后状态为 `ON_SALE`。
- 买家可以收藏商品。
- 买家可以创建会话。
- 消息发送支持幂等重放。
- 旁观者读取消息返回隐藏式 404。
- 交易首次创建返回 201。
- 同 key 重试返回相同 201 响应体。
- 换 key 请求返回已有交易和 200。
- 旁观者读取交易返回 404。
- 买家调用卖家专属接受动作返回 403。
- 卖家接受交易，双方确认后交易为 `COMPLETED`，商品为 `SOLD`。
- 收藏、会话、商品详情和交易投影都显示 `SOLD`。
- 商品详情和公开投影不泄露学号。
- 记录公网延迟基线。
- 校验跨 Gateway、Marketplace、Messaging、Account 和 Outbox worker 的 Trace。
- 校验 Outbox 积压为 0。
- 允许这些 E2E 数据写入生产学习环境。

**CI、PR 与部署**

- readiness、E2E、Trace、Outbox 任意失败都必须让流程失败。
- 正式用户上线前必须改为 Nginx HTTPS，并关闭 `18083` 公网直连。

**前端接入**

- 前端业务代码统一请求相对路径 `/api/v1`。
- 开发环境使用 Vite/开发服务器代理到 `[公网地址]:18083`。
- 图片 `/media` 也通过代理转发。
- 生产环境由 Nginx 将域名的 `/api/v1` 和 `/media` 转发到 `127.0.0.1:18083`。
- Nginx 配置、证书申请、配置校验和 reload 最终都纳入自动部署。
- 正式接入前需要域名和 HTTPS 证书。
